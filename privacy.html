Kebijakan Privasi Nexus PDF Workspace

Tanggal berlaku: 21 September 2026

Nexus PDF Workspace adalah aplikasi desktop untuk membaca dan mengolah dokumen PDF. Kebijakan ini menjelaskan data yang aplikasi akses, kapan data meninggalkan komputer Anda, dan pilihan yang tersedia bagi Anda.

Dokumen dan pemrosesan lokal

Aplikasi membaca dokumen yang Anda pilih dan menyimpan hasil ke lokasi yang Anda tentukan. Operasi baca, edit, OCR lokal, konversi, pencetakan, dan audit PDF berjalan pada komputer Anda. Aplikasi tidak mengunggah dokumen untuk operasi tersebut.

Aplikasi menyimpan pengaturan, riwayat berkas, dan pemulihan sesi pada profil Windows Anda. Anda dapat menghapus riwayat dari aplikasi. Setelah mencopot aplikasi, data kompatibilitas lama yang masih ada dapat dihapus dari folder %APPDATA%\NexusPDFPro.

Telemetri opsional

Telemetri nonaktif pada pemasangan baru. Jika Anda mengaktifkannya dari menu Pengaturan, aplikasi mengirim data berikut ke Supabase melalui HTTPS:

  • nama profil Windows lokal dan ID perangkat;
  • versi aplikasi, versi dan arsitektur Windows, serta kapasitas RAM;
  • status aktif, durasi pemakaian, dan waktu terakhir aktif.

Data dipakai untuk mengukur penggunaan, mendiagnosis masalah rilis, dan mengetahui versi yang masih digunakan. Supabase menyimpan setiap instalasi dengan identitas anonim dan membatasi akses melalui Row Level Security. Data disimpan sampai Anda meminta penghapusan atau layanan telemetri dihentikan. Telemetri dapat dimatikan kembali dari Pengaturan; setelah itu aplikasi menghentikan pengiriman berikutnya.

Google Gemini

Fitur AI memakai Google Gemini dan API key milik Anda. Aplikasi meminta persetujuan sebelum mengirim teks, gambar halaman, atau bagian dokumen yang Anda pilih ke Google. Tidak ada konten dokumen yang dikirim melalui Gemini jika Anda menolak konfirmasi.

API key disimpan di Windows Credential Manager. Google memproses data sesuai ketentuan dan kebijakan layanan Gemini yang terkait dengan API key Anda. Hapus kredensial NexusPDFPro / gemini_api_key dari Windows Credential Manager untuk menghapus key dari komputer.

Keamanan dan pihak penerima

Aplikasi memakai HTTPS untuk komunikasi dengan Supabase dan Google. Supabase menerima telemetri setelah opt-in. Google menerima konten yang Anda setujui untuk fitur Gemini. Kami tidak menjual data pribadi dan tidak memakai jaringan iklan.

Akses, penghapusan, dan kontak

Kirim permintaan akses atau penghapusan telemetri dan pertanyaan privasi ke salmanir55@outlook.com. Tim dukungan akan memberi petunjuk untuk menemukan informasi instalasi yang diperlukan. Verifikasi tambahan dapat diminta untuk mencegah penghapusan data milik orang lain.

Nexus PDF Workspace Privacy Policy

Effective date: September 21, 2026

Nexus PDF Workspace is a desktop application for reading and processing PDF documents. This policy describes the data the app accesses, when data leaves your computer, and the choices available to you.

Documents and local processing

The app reads documents that you select and saves output to locations that you choose. Reading, editing, local OCR, conversion, printing, and PDF inspection run on your computer. The app does not upload documents for those operations.

The app stores settings, file history, and session recovery data in your Windows profile. You can clear history in the app. After uninstalling, remaining legacy compatibility data can be removed from %APPDATA%\NexusPDFPro.

Optional telemetry

Telemetry is off on a new installation. If you enable it in Settings, the app sends the following data to Supabase over HTTPS:

  • your local Windows profile name and a device identifier;
  • app version, Windows version and architecture, and installed RAM;
  • active status, accumulated usage time, and last-active time.

We use this data to measure usage, diagnose release problems, and identify app versions that remain in use. Supabase stores each installation under an anonymous identity and restricts access with Row Level Security. We retain the data until you request deletion or we discontinue the telemetry service. You can turn telemetry off in Settings to stop future transmissions.

Google Gemini

AI features use Google Gemini and your own API key. The app asks for consent before sending selected text, page images, or document sections to Google. No document content is sent through Gemini if you decline.

The API key is stored in Windows Credential Manager. Google processes sent data under the Gemini terms and privacy policy associated with your API key. Remove the NexusPDFPro / gemini_api_key credential from Windows Credential Manager to delete the key from your computer.

Security and recipients

The app uses HTTPS for communication with Supabase and Google. Supabase receives telemetry after opt-in. Google receives content that you approve for Gemini features. We do not sell personal data or use advertising networks.

Access, deletion, and contact

Send telemetry access or deletion requests and privacy questions to salmanir55@outlook.com. The support team will explain how to find the installation information needed to locate the correct record. Additional verification may be requested to prevent deletion of another person's data.
